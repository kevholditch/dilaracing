# Dila Racing

Get the max out of your steering wheels and lightboxes with SimHub: custom colour themes, rev-limit flashes, pit-limiter effects and race flags.

An early prototype for the Simagic Neo X, Cube Controls F-Pro and iFlag boxes, using SimHub for telemetry and device communication.

Build on Windows with SimHub installed:

```powershell
.\build.ps1
```

See [setup and testing](docs/SETUP.md) for installation and hardware checks.
